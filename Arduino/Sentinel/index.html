Help

Getting started

Keep this page open while surveying. BLE records continuously. WiFi scans on its selected schedule or when you tap Scan WiFi now.

RSSI, proximity, and movement

RSSI is received signal strength in dBm; values closer to zero are stronger. Tap a colored BLE legend button to show or hide that band; this changes the display only and never deletes recorded evidence. Gray includes very weak devices and devices not seen for five seconds. Clear filters restores every band, ignored device, RSSI level, and search result. WiFi trends compare consecutive completed surveys: at least +4 dB is stronger, −4 dB is weaker, and smaller changes are stable. BLE signal bands and trends are affected by walls, bodies, antennas, and reflections—they are not exact distance, location, direction, or proof of movement.

Pause and ignored devices

Pause display freezes the visible table while evidence continues recording. Ignore hides a device from the normal view; enable Show ignored to reveal it again.

Sessions and browser storage

Start new session closes the current session and begins another. Session Library can review, rename, compare, export, or delete saved sessions. Retention is disabled by default. Clear browser evidence permanently removes everything from this browser.

Exports and reports

JSON is the complete machine-readable evidence package with timestamp provenance, annotations, schema version, and SHA-256. Import / verify checks whether a JSON export changed. CSV is best for spreadsheets. Print / PDF creates a readable report. Saved detail-card images document one selected observation.

Insights and annotations

Insights report explainable facts such as a new identifier, strong signal, changed advertisement, open WiFi, duplicate SSID, or changed channel/security. Tap an insight to open the related device card. They never declare a device malicious. Detail-card annotations are analyst-supplied and remain separate from observations.

WiFi and BLE limitations

WiFi security is the access point's advertised mode, not proof that it is trustworthy. Randomized BLE addresses may rotate. A sighting does not prove a person's identity or continued presence.

Evidence handling

Enter a case ID, investigator, location label, and notes before exporting. Keep the original JSON and its SHA-256 hash. Use this passive survey only where scanning is permitted.
