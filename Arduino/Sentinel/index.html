Getting started

Keep this page open while surveying. BLE records continuously. Wi-Fi scans on its selected schedule or when you tap Scan Wi-Fi now.

RSSI, proximity, and movement

RSSI is received signal strength in dBm; values closer to zero are stronger. Wi-Fi trends compare consecutive completed surveys: at least +4 dB is stronger, −4 dB is weaker, and smaller changes are stable. Distance labels and BLE movement arrows are estimates affected by walls, bodies, antennas, and reflections—not exact locations or directions.

Pause and ignored devices

Pause display freezes the visible table while evidence continues recording. Ignore hides a device from the normal view; enable Show ignored to reveal it again.

Sessions and browser storage

Start new session begins a separate evidence collection without deleting earlier browser records. Clear browser evidence permanently removes all saved sessions from this browser.

Exports and reports

JSON is the complete machine-readable evidence package. CSV is best for spreadsheets. Print / PDF creates a readable report. Saved detail-card images document one selected observation.

Wi-Fi and BLE limitations

Wi-Fi security is the access point's advertised mode, not proof that it is trustworthy. Randomized BLE addresses may rotate. A sighting does not prove a person's identity or continued presence.

Evidence handling

Enter a case ID, investigator, location label, and notes before exporting. Keep the original JSON and its SHA-256 hash. Use this passive survey only where scanning is permitted.
